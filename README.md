# Portfolio Web - Zhanpar Isman Andria

Website portofolio satu halaman untuk **Zhanpar Isman Andria**, seorang Software Quality Assurance Engineer. Situs ini menampilkan profil profesional, keahlian, pengalaman kerja, proyek, dan informasi kontak.

## Fitur

- Desain responsif untuk desktop dan perangkat seluler.
- Navigasi dengan smooth scrolling dan menu hamburger untuk tampilan seluler.
- Bagian hero dengan ilustrasi terminal QA.
- Ringkasan statistik pengalaman dan cakupan pengujian.
- Daftar keahlian QA, pengalaman, dan proyek automation testing.
- Animasi reveal saat kartu skill, pengalaman, proyek, dan statistik terlihat di layar.
- Tautan langsung ke GitHub, LinkedIn, dan email.

## Teknologi

- HTML5
- CSS3
- JavaScript (vanilla)
- [Tailwind CSS](https://tailwindcss.com/) via CDN
- [Lucide Icons](https://lucide.dev/) via CDN
- [Font Awesome](https://fontawesome.com/) via CDN
- Google Fonts: Inter dan JetBrains Mono

## Struktur Proyek

```text
.
├── index.html   # Markup dan konten seluruh halaman
├── style.css    # Animasi dan gaya kustom
├── script.js    # Menu seluler, ikon, dan scroll reveal
└── README.md    # Dokumentasi proyek
```

## Menjalankan Secara Lokal

Proyek ini tidak memerlukan instalasi dependensi atau proses build. Jalankan web server statis dari root proyek:

```bash
python3 -m http.server 8000
```

Kemudian buka [http://localhost:8000](http://localhost:8000) di browser.

## Kustomisasi Konten

Perbarui konten portofolio, tautan sosial, proyek, dan informasi kontak di `index.html`. Gaya serta animasi tambahan berada di `style.css`, sedangkan perilaku interaktif halaman berada di `script.js`.
